# HR Attrition Analysis

Analysis of IBM HR Employee Attrition dataset using Python, SQL, and Power BI 
to identify key drivers of employee turnover.

## Tools Used
Python (Pandas, Matplotlib, Seaborn), SQL (SQLite), Power BI

## Key Insights
1. Overall attrition rate: 16.1%
2. Sales has the highest attrition rate (20.6%), despite R&D having more total departures
3. Overtime is the strongest driver — 30.5% attrition vs 10.4% for non-overtime employees
4. Employees who leave earn less on average (₹4,787 vs ₹6,832)
5. Younger employees (avg age 33.6) leave more than older employees (avg age 37.6)
6. Attrition rate drops as job satisfaction increases (23% → 11.5%)
